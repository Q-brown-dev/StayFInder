# 🏡 StayFinder

**StayFinder** is a modern travel and accommodation web application inspired by platforms such as Airbnb. It allows users to explore stays, discover experiences, and browse online experiences through a clean and responsive interface.

The project was built as a frontend web development project using **HTML, CSS, and JavaScript**.

## ✨ Features

### 🏠 Stays

- Browse available accommodation options
- Explore popular homes and hotels
- View accommodation cards with images, locations, ratings, and pricing
- Search interface for finding stays

### 🌎 Experiences

- Discover activities and experiences
- Browse different experience categories
- Explore activities such as food tours and local experiences
- Experience cards with images, locations, ratings, and pricing


### 💻 Online Experiences

- Browse experiences that can be enjoyed online
- Explore different online experience categories
- View online experience cards with images, descriptions, ratings, and pricing

### 🔍 Search Interface

StayFinder includes search interfaces designed around:

- Location
- Check-in / date
- Guests
- Experience categories

### 📱 Responsive Design

The application is designed to work across different screen sizes:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet
